# Expense Tracker

Expense tracker with a React/Vite frontend and an Express/Prisma backend.

## Project Structure

- `src/` and `store/` contain the frontend app.
- `backend/` contains the API, upload handling, Prisma schema, and migrations.

## Environment Variables

Environment files are intentionally ignored by git:

- `.env`
- `.env.*`
- `backend/.env`

Create local `.env` files as needed, but do not commit secrets.
